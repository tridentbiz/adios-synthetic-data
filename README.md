## Installation

### Standalone Installation
```bash
git clone https://github.com/tridentbiz/adios-synthetic-data.git
cd adios-synthetic-data
./install.sh
```

### AdiOS Integration
```bash
cd /path/to/0001-adios
git submodule add https://github.com/tridentbiz/adios-synthetic-data.git plugins/synthetic-data
adios plugin install synthetic-data
```
